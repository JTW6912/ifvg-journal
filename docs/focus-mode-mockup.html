静态 mockup，数据和图都是现场画的假 K 线，故意做成五种不同宽高比（16:9 / 21:9 / 4:3 / 2.33:1 / 16:10）， 用来验证「不裁图 + 高度封顶」在各种截图习惯下的表现。
要试的东西：J / K 或 ↑ / ↓ 跳上下一笔 · 点图开原图 · 切三档高度 · 字段「右侧」↔「底部」来回切，看图能变多大 · 打开「遮挡结果」再点揭晓 · 右上角切亮/暗主题。
实测的取舍（1680×1000 窗口、高度档「大」）：字段放右侧，图 1246px 宽、高度 526~780 不等——宽图先被列宽卡住， 高度封顶其实没生效；但一整笔正好一屏，滚动节奏最舒服。字段放底部，图 1040~1586px 宽、高度 669~780， 明显更大也更齐，代价是一笔要占 900~1100px，超过一屏，字段得往下扫一眼才看得到。
