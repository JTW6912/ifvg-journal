# 新账号新手指南：默认字段说明 & 哪些改不得

*(English version: [new-user-guide.md](new-user-guide.md))*

## 为什么要写这份指南

注册账号之后，IFVG Journal 会给你的账号写入一套默认字段结构（在**设置**页可以看到）。每个
字段都可以自己改，这本来就是这个应用最大的卖点。但默认字段里有几个比较特殊——统计引擎认的
不只是字段角色，还会直接比对**选项的具体文字**。改错地方不会报错，只会让你之后录的交易悄悄
从统计里消失，数字慢慢就对不上了。

这份指南讲清楚每个默认字段是干嘛的，以及哪些部分可以随便改，哪些部分应该原样用、别去改它。

## 默认字段一览

| 字段（中文标签） | 类型 | 默认选项 | 角色 | 作用 |
| --- | --- | --- | --- | --- |
| 日期 | 日期 | — | `date` | 交易日期，驱动月历/月度页和排序。 |
| 交易时段 | 单选 | London / NYAM / Asia / Other | 无 | 这笔交易发生在哪个交易时段。 |
| 入场时间 | 时间 | — | 无 | 入场时间点。 |
| 方向 | 单选 | Long / Short | 无 | 交易方向。 |
| 模型 | 单选 | ifvg | `model` | 用的哪个交易模型/策略，驱动按模型拆解和筛选。 |
| 入场方式 | 多选 | displacement / IFVG / CISD | 无 | 入场的确认依据。 |
| 做了还是避免 | 单选 | Taken / Faded | `taken` | 这笔到底进场了还是只是观察没做，驱动「只算已入场」这个统计口径。 |
| 结果 | 单选 | W / L / BE / BE -> L / BE -> W | `result` | 交易结果。整个分析页几乎都靠它才能跑起来。 |
| RR | 数字 | — | `r_multiple` | R 倍数/实际盈亏 R，驱动总 R、EV、盈亏比。 |
| 人为错误 | 单选 | yes / no | `human_error` | 执行是否偏离了计划，驱动「排除人为错误」这个统计口径。 |
| 自评等级 | 单选 | A+ / A / B+ / B / C / D | 无 | 自己给这个 setup 打的质量分。 |
| 目标类型 | 多选 | 5M ITH/L、15M ITH/L、30M+ ITH/L、BSL/SSL、PDH/L 等 | 无 | 这笔交易打的是哪种流动性/关键位。 |
| 笔记 | 多行文本 | — | 无 | 入场时写的想法。 |
| 复盘笔记 | 多行文本 | — | 无 | 事后复盘。 |
| 截图 | 链接/截图 | — | `screenshot` | 图表截图链接，卡片缩略图和灯箱靠它。 |

如果你注册时选的是英文界面，这十四个字段会是英文标签（Date、Session、Entry Time、
Direction、Model、Entry Type、Taken / Faded、Result、RR、Human Error、Self Grade、
Target Type、Notes、Review Notes、Screenshot）—— id、选项值、角色底层完全一样，只是显示
标签跟着注册时的语言走一次（详见主 [README](../README.zh-CN.md) 的「界面语言」一节）。

## 唯一需要真正搞懂的概念：角色

设置页可以给每个字段最多打一个**分析角色**：`date`、`model`、`taken`、`result`、
`r_multiple`、`max_rr`、`human_error`、`screenshot`。统计引擎从来不看字段叫什么名字、
标签是什么——只看哪个字段被打了哪个角色。

这一层是安全的。坑在更深一层：其中三个「逻辑类」角色，代码里还直接写死比对**原始选项的
具体文字**：

| 角色 | 默认打在哪个字段上 | 代码里认的具体值 |
| --- | --- | --- |
| `taken` | 做了还是避免 | `"Taken"`（只有值完全等于这个字符串的交易才算进「只算已入场」这个口径） |
| `result` | 结果 | `"W"`、`"L"`、`"BE"`、`"BE -> W"`、`"BE -> L"` |
| `human_error` | 人为错误 | `"yes"`（只有值恰好是这个才算「有人为错误」，其他任何值包括空白都算「没有」） |

## 可以放心改的

- 改字段的**显示标签**——比如把「做了还是避免」改成「进场/观望」之类。引擎认的是内部 id
  和角色，从来不看标签，改标签永远不会出问题。
- 拖拽调整字段顺序、在卡片上隐藏某些字段、改动**没有打角色**的字段类型。
- 加全新的字段，或者给没打角色的字段（交易时段、方向、入场方式、自评等级、目标类型、
  笔记、复盘笔记……）加新的选项值——想加多少加多少。
- 自己加一个 `max_rr`（数字类型）字段并打上这个角色——默认字段模板里没有它，但加上之后
  「R 捕获率」这个指标就能直接用。

## 千万别这么改——会悄悄把统计弄坏

- **改动打了角色的字段的选项列表**——「做了还是避免」「结果」「人为错误」这三个。如果你
  去设置页把选项「Taken」改成别的字样（哪怕只是翻译成「已入场」），改动**之后**录的每一笔
  交易都会存成新的值，但统计引擎认的还是原来那个字符串 `"Taken"`。这些新交易会悄悄从
  「只算已入场」口径、胜率、EV、盈亏比里消失——不会报错，数字只是慢慢变得不对劲。
- 「结果」也一样：把选项「W」改成「赢」或者「Win」，之后每一笔赢的交易都不会再被引擎认成
  赢，因为它比对的还是精确的 `"W"`。
- 「人为错误」也一样：改了「yes」/「no」的文字，「排除人为错误」这个口径就失效了。
- **把某个字段的角色去掉**（改回「无」），或者把角色挪到另一个选项不一样的字段上——要么
  这个指标直接失效，要么统计出来的数字是错的，取决于新字段的选项值。
- **在设置页试着调整角色时**——如果你把某个角色打到一个原本没有它的字段上，原来持有这个
  角色的字段会被**静默摘掉**角色（改回「无」），没有任何提示弹窗。随手试改的时候很容易
  不小心弄错，改完最好回头确认一下每个角色现在挂在哪个字段上。
- **删掉打了 `result` 角色的字段**——按应用本身的设计，这个字段是「整个分析页能不能跑」的
  前提；删掉它分析页直接瘫痪。
- **改动打了角色的字段的类型**——比如把「结果」从单选改成自由文本。自由文本永远不可能精确
  等于 `"W"` / `"L"` / `"BE"`，统计就全对不上了。

**如果已经这么改了：** 回设置页，把这三个字段的选项文字改回原样（`Taken`、`Faded`、`W`、
`L`、`BE`、`BE -> L`、`BE -> W`、`yes`、`no`），保证存储的选项值和原来一致。字段的显示
标签、选项排序都还是可以随便调，只是这三个字段的**选项文字本身**别动。

**一句话总结：** 「做了还是避免」「结果」「人为错误」，以及打了 `date` / `model` /
`r_multiple` / `screenshot` 角色的那几个字段——别去改它们的结构，学会照着用就行。除此之外
的字段结构，随你怎么改。

## 怎么拿到截图链接（TradingView / fx 平台）

「截图」这个字段要的是一个指向图片的**链接**，不是上传文件。最快的拿法：

1. 在 TradingView（或者你用的 fx 交易/看盘平台）上打开图表。
2. 按 **Alt+S**（截图分享功能）。这会把当前图表截图上传，并自动把一个公开链接复制到剪贴板。
3. 把这个链接直接粘贴到交易记录的「截图」字段里就行。

卡片缩略图和灯箱只是渲染你粘贴进去的那个链接——任何能公开访问的图片链接都能用，
Alt+S 只是从图表拿到这种链接最快的办法。

有一个要求：链接必须能直接打开就是图片本身（`<img>` 标签能直接加载的那种），而不是一个
「打开后网页里显示图片」的分享页链接。如果粘贴错成了网页链接，会重试两次，然后变成一个
占位图标，并给出手动「重试」按钮，而不是正常显示缩略图。
