# Acceptance: approved company-summary implementation

These are production implementation assertions, updated from the exploratory preview criteria before the first development acceptance freeze. All assertions start failing; the prototype's successful checks are design evidence only, not completion of these requirements.

- A1 (R1/R2/R5; unit + offline UI): All seven fields and scoped company rows match the existing renderer/helpers for identical inputs; default net-descending ordering and alternative investment/receipts/ROI ordering preserve every value, input array and common bar scale. Current counts do not replay dates; period cash/events retain existing company/group and global-range semantics.
- A2 (R2/R3/R7; unit + geometry): Shared symmetric net bars express correct sign/zero and common amount scale. Pass tracks use actual ratios; unknowns stay dashes. Zero/negative investment, refund surplus, pending-only, no-decided-attempt, large amounts and tied/unknown sorting produce finite safe output and no invented financial result.
- A3 (R4/R6; offline browser): Field i prompts work with hover, focus, tap and Escape, retain hoverable content and accurate ARIA associations, and clear on redraw/modal/navigation. Mobile keyboard focus reveals obscured columns past the fixed company column; tips remain inside viewport and touch targets are at least 44px.
- A4 (R3/R6; offline browser/sensory): Actual-source desktop and narrow layouts retain all seven metrics, logos/fallback, full monetary text and local-only table overflow. Seven palettes, light/dark, zh/en, custom P&L binding and reduced motion retain existing theme semantics; no preview controls or global shell changes appear.
- A5 (R7; unit + offline UI): Classic zh/en HTML and existing section visibility are unchanged. Unfiltered fewer-than-two companies stays hidden; a filtered single company is displayed. Existing account-empty and invalid-finance paths, prior finance/funnel/monthly UI, monthly line toggle and ledger expansion still behave as before.
- A6 (R5/R8; unit + offline browser): Sort is local and defaults/reset correctly across identity, layout and overview exit; in-view range/filter/theme/locale changes preserve it. Sorting keeps focus/scroll and does not replace monthly groups, dirty/busy forms or modal priority. No new storage, network, persistence, renewal or permissions path is introduced.
- A7 (R8; static + unit + offline UI): Text/attributes are escaped, unsafe logo values cannot execute and malformed geometry/sort input cannot inject markup. Full tests, bundle, syntax and diff checks pass; offline runtime has no config/init/Supabase calls. Source changes are restricted to the approved component/seams/styles/locale/tests. No production credentials, private screenshots/data, dependency/schema/API changes or unauthorized Git publication.

Native acceptance/independent review and any subsequent formal verification remain separate. Never mark these passing from prototype evidence alone.
