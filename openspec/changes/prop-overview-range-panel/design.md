# Implementation Design

## Context

原生JS共享作用域按数字前缀拼接；页面用字符串生成并按区域替换。Prop的账本已完整分页加载，propScoped负责公司/分组，propSum定义费用、退款、到账和ROI口径。

## Goals / Non-Goals

实现已批准的现代资金面板和本地范围交互。classic及下方图表不变；不改续费、表单、目录、数据结构、认证或持久化接口；不使用真实业务数据验证。

## Decisions

1. 范围及累计点为领域纯函数，复用既有金额规范化；图表按实际有记录的日期建立稀疏阶梯点，避免遍历多年空白日。
2. 仅modern调用新的概览组合入口。当前阶段计数不套财务日期，财务指标共用一批过滤流水。
3. 初始全部时间；相对快捷范围按本地今天计算，自定义边界包含首尾。已应用范围和未完成草稿分离。
4. 日期与Tooltip挂载到独立body浮层根，使用唯一命名空间、可取消的定时器和明确清理接口；不破坏现有表单或全局事件。
5. 新CSS限定modern和Prop命名空间，复用主题与pnl变量；shadcn语义不覆盖全局accent。
6. 六个说明触发器共享控制器。复制布局理念，不复制预览用户数据、样例时间限制或主题调试控件。
7. 负投入/零投入如实显示；无法表达为正值收益分段时采取清晰的非误导表示，不强制把金额归零。无有效日期不编造历史点。

## Risks / Trade-offs

区域重绘会替换触发器，必须清理或恢复焦点；英文文案及大金额需窄屏检查。原型中的金额样例不是生产数据源。既有真实初始化会补续费，因此验证页必须排除自动认证初始化并禁止业务网络。

## Validation

先加失败的纯逻辑/渲染回归测试，再实现；使用实际源码的合成离线mock检查日期、Tooltip和布局，独立规格/质量审阅后再汇报。业务源码的提交/推送不在此次授权内。
